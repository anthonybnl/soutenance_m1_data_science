# 🎯 Système Intelligent Multi-Modèles pour la Rétention Client

> **Projet M1 Data Science** - Expert en Ingénierie de Données (RNCP40875 - Bloc 2)

Plateforme intelligente de prédiction du churn client et d'évaluation du risque de revenus pour entreprises SaaS, télécom et services par abonnement.

---

Données : https://www.kaggle.com/datasets/miadul/customer-churn-prediction-business-dataset

## 📋 Description du Projet

Ce projet vise à développer un **système d'aide à la décision complet** capable de :
- ✅ Prédire la probabilité de résiliation client (churn)
- ✅ Identifier les segments clients à haut risque
- ✅ Évaluer l'impact financier des résiliations
- ✅ Fournir des recommandations actionnables via un dashboard interactif

### 🎓 Objectifs Pédagogiques
- Maîtriser le pipeline complet d'un projet Data Science (de l'EDA au déploiement)
- Comparer rigoureusement plusieurs algorithmes (ML classiques + Deep Learning)
- Développer une solution explicable et orientée business
- Créer une interface décisionnelle pour utilisateurs métier
